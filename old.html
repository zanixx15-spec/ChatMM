⚙️ API Settings

OpenRouter API Key ထည့်ပါ။ Key ကို ဒီ browser ရဲ့ local storage မှာ သိမ်းထားမည်ဖြစ်ပြီး website code ကို ဝင်ကြည့်နိုင်သူများက မြင်နိုင်နိုင်ပါတယ်။ Public website မှာ တိုက်ရိုက်မထည့်ဘဲ backend proxy သုံးဖို့ အကြံပြုပါတယ်။

API Key ကို OpenRouter မှာ ရယူနိုင်ပါတယ်။ Provider အလိုက် ကုန်ကျစရိတ်ရှိနိုင်ပါတယ်။
